# Icon Working Evidence

This directory is reserved for original noBS CAD icon working evidence that
cannot be represented directly in `src/components/icons.tsx`, such as design
notes, construction sketches, or intermediate vector source.

No separate pre-existing working files were present when this directory was
established on 2026-07-25. The TypeScript geometry in
`src/components/icons.tsx` is the canonical source for the current glyphs.

For future icon work:

1. Store original working files here before exporting or transcribing final
   paths. Never overwrite an earlier draft.
2. Use filenames containing the icon ID and ISO date, for example
   `shell-2026-07-25-v01.svg`.
3. Do not store third-party screenshots, traced artwork, or vendor assets.
4. Commit the draft, final source, provenance update, and review record
   together.
5. If an external licensed asset is ever approved, keep it in a clearly named
   subdirectory with its complete license and source URL.
