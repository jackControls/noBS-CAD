# ADR 0005 — Seven main goals

- Status: Proposed
- Date: 2026-07-27

## Context

The project needs a short shared north star for humans and agents. Detail lives in `docs/goals.md` (mission-ecosystem PR).

## Decision (proposed)

Track these as the main goals:

1. Agentic CAD
2. Additive manufacturing (3MF with materials/colors)
3. Standards
4. Rust
5. Fully offline
6. Simulation
7. Education (tutor-style, Synthesis Tutor–like)

Near-term engineering still prioritizes reliability, 3MF, MCP, and tests — simulation and full education UX come after foundations.

## Consequences

- New features should map to at least one goal in the PR or issue.
- Docs stay plain language so both humans and agents can follow them.
