# Showcase stills

Actual native noBS CAD renders, retained here so the repository front door does
not depend on a private download site. Large videos/GIFs are release assets.

- `bench.png`: completed garden-bench replay; recording recipe revision
  `59a27f4c`, 595 steps and 47 checks. Video is a 30-second edited construction.
- `vise.png`: poster from the 2:21 detailed vise montage. Full construction at
  `53fb4ad5` passed 1,834 steps and 127 checks; later pickups at `1e36fb0` show
  the opening, screw detail and continuous final orbit. The recorded recipe is
  unchanged between those revisions.
- `turbine.png`: current native assembly from the qualified development kit at
  `f56db867`. This is a still image, not a frame from a turbine construction video.

Recipe sources are in [`examples/scripts`](../../../examples/scripts/README.md).
Digital checks do not replace physical prototype qualification; see
[`docs/flagship-examples.md`](../../flagship-examples.md).
