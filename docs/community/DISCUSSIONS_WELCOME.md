# Discussions welcome post

## How to enable Discussions (one-time, repo owner only)

Repo **Settings → General → Features → GitHub Discussions → Enable**.
Pick a first category announcement ("Announcements" or "General" both work —
create a new category called **General** if the default set is missing it).

## Paste this as the first post (category: General)

---

**Title:** 👋 Welcome + the fastest way to help: break the CAD on purpose

**Body:**

> Welcome to noBS CAD — local-first, open-source mechanical CAD. No cloud, no
> account, no subscription, no telemetry: your models never leave your
> machine. LGPL-2.0-or-later, built on the OCCT kernel with a Rust modeling
> core.
>
> **This is pre-alpha.** Expect rough edges — that's the point of the project
> right now. Two ways to help:
>
> 1. **The Edge-case hunt** (pinned issue): try to model something real, or
>    work through the challenge list of nasty geometry. Every report becomes a
>    regression test: https://github.com/jackControls/noBS-CAD/issues/45
> 2. **Just hang out**: show what you're modeling, ask questions, suggest
>    workflows. Real parts beat feature checklists — we want to know what you
>    actually need, not what a CAD command list looks like.
>
> Reporting guide: `docs/EDGE_CASE_HUNT.md` in the repo.
>
> Introduce yourself below — what do you want to design in a no-BS CAD?
