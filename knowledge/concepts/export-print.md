# Export and print

## Today

- STEP import
- AP242 STEP export (geometry interchange; not editable history)

## Recommended next

- **3MF** export from OCCT tessellation (preferred print package format)
- **STL** fallback for broader slicer support
- MCP tools: `solid_export_3mf`, `solid_export_stl`
- Preserve units in metadata where the format allows

3MF is the manufacturing mesh package; it does not replace STEP for CAD interchange.
